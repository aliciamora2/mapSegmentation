# mapSegmentation

This repository contains the implementation associated with the following research paper: **"Segmenting Maps by Analyzing Free and Occupied Regions with Voronoi Diagrams"**, presented at ICINCO 2022.

The project provides a MATLAB-based approach to segment grid maps by analyzing both free and occupied space using Voronoi diagrams, facilitating topological mapping and navigation for mobile robots.
